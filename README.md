# 🎧 Audio Visualizer

A creative Python project that transforms audio signals into dynamic animated visuals in real-time.

---

## ✨ Features
- 🎆 Multiple visualization modes (Particles, Waves, Mandala, Nebula)
- 🎵 Beat detection with reactive animations
- 🌈 Frequency-based color transitions
- 🔊 Amplitude-driven motion and scaling
- 🌀 Smooth motion trails (motion blur effect)

---

## 🛠 Tech Stack
- Python
- Pygame
- Librosa
- NumPy
- SoundDevice
